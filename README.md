# Ардуино — интерактивная лаборатория

Учебный симулятор Arduino Uno с наглядной макетной платой, настоящим выполнением Arduino-кода и живой визуализацией компонентов.

## Возможности

- Установка светодиодов, резисторов, кнопок, потенциометров, датчиков освещённости и температуры, HC-SR04, зуммера, RGB-светодиода, сервопривода, DHT22 и DS18B20.
- Соединение контактов проводами с учётом внутренних связей макетной платы и дорожек питания.
- Перемещение и дублирование деталей, автоподгонка масштаба, ручные изгибы проводов и подсветка всей электрической цепи.
- Проверка питания, сигнальных соединений, резисторов в цепях светодиодов и коротких замыканий.
- Редактор Arduino C++ с подсветкой синтаксиса, компиляцией и выполнением машинного кода ATmega328P.
- GPIO, ШИМ, АЦП, USART и библиотека Servo; двусторонний монитор порта с поддержкой UTF-8.
- Цифровые протоколы DHT22 и 1-Wire: температура и влажность, Convert T, scratchpad и CRC DS18B20.
- Десять готовых экспериментов и восемь уроков с сохранением прогресса.
- Изменение схемы и параметров датчиков во время выполнения программы.
- Локальное сохранение схемы, кода, выбранного эксперимента и прогресса, адаптивный интерфейс и PWA-режим.

## Запуск

```bash
npm install
npm run dev
```

Производственная сборка:

```bash
npm run build
npm run preview
```

Для компиляции sketch требуется подключение к интернету: исходный код отправляется в публичный сервис Wokwi Hexi, после чего полученный Intel HEX выполняется локально в браузере. Схема и код сохраняются только в текущем браузере через `localStorage`.

## Структура

- `src/components/CircuitBoard.tsx` — SVG-плата, макетка, детали и провода.
- `src/lib/circuit.ts` — геометрия контактов, электрические сети и подсказки по схеме.
- `src/lib/avrRunner.ts` — компиляция, AVR8js, периферия и Serial.
- `src/lib/sensorProtocols.ts` — протоколы DHT22 и DS18B20 / 1-Wire.
- `src/components/CodePanel.tsx` — CodeMirror и монитор порта.
- `src/data/experiments.ts` — уроки, программы и готовые схемы.
- `src/App.tsx` — состояние лаборатории и взаимодействия.

## Границы модели

Эмулируются ATmega328P и его цифровая периферия. Аналоговая часть учебная: напряжения датчиков и логические соединения моделируются, но полноценный расчёт токов, сопротивлений и паразитных эффектов не выполняется.
